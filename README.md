# 帕奇 Skill 中心（本地展示原型）

这是一个无后端、无外部依赖的静态展示页原型，适合先在本机确认页面和内容结构。

## 本地预览

在本目录打开 `index.html` 即可预览；如果浏览器限制本地文件跳转，可用任意静态文件服务器提供本目录。

## 后续更新

- 技能卡片数据：编辑 `app.js` 顶部的 `skills` 数组。
- 页面内容与布局：编辑 `index.html`。
- 颜色和响应式样式：编辑 `styles.css`。

## 飞书接入边界

飞书菜单需要填写一个员工设备可以访问的 HTTPS 地址。`file://`、`localhost`、`127.0.0.1` 只能本机预览，不能作为正式菜单链接。

正式接入前需要把这个静态页面发布到公司批准的网页/静态托管位置；本原型不会自动修改飞书菜单，也不会开放生产 VM 入站端口。
